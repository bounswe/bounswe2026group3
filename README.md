# Neighborhood Accessibility Mapper

**CMPE354 - Group 3**

A crowdsourced platform documenting accessibility features of local businesses, transit stops, and sidewalks. Includes route planning considering mobility needs.

## Project Description

Neighborhood Accessibility Mapper connects people with mobility challenges to accessible spaces and helps businesses willing to improve with those who need accommodations. Users can:

- Plan accessible routes between two locations based on their mobility profile
- View crowdsourced accessibility data (ramps, slopes, obstacles) on a static map
- Report obstacles and rate the accessibility of locations
- Navigate using street names and landmarks without real-time GPS tracking

## Key Features

- **Static Route Planning** — Generates a single optimal route based on user's mobility constraints (max slope, sidewalk width, curb ramps)
- **Crowdsourced Obstacle Reporting** — Users report barriers like construction, broken sidewalks, and steep slopes
- **Accessibility Markers** — Visual overlays for ramps, slopes, and obstacles on the map
- **No Re-routing** — The app acts as a fixed visual guide; the route does not change once generated
